# Service logos

These full-color and brand-native SVGs are bundled with KeyNest. Recognized
services render the files directly with an ordinary image element, preserving
the colors inside each asset without CSS masks, filters, or recoloring.

Sources:

- SVG Logos via Iconify (`@iconify-json/logos` 1.2.14), CC0-1.0.
- Instagram from Skill Icons via Iconify (`@iconify-json/skill-icons` 1.2.4), MIT.
- Amazon 2024 and Canva wordmarks from Wikimedia Commons, public-domain
  text logos subject to their respective trademark rights.

No logo is requested from these sources at runtime.
